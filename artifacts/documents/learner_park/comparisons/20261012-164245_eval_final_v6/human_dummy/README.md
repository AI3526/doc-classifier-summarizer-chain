# 가상 채점 (미리보기용)

- `human_sheet_rater1.csv`는 **실제 사람(사용자)이 채점한 1번 시트를 그대로 복사**한 것입니다.
- `human_sheet_rater2~4.csv`는 `scripts/make_dummy_from_rater1.py`가 1번 시트를 조금씩 바꿔 만든 **가상 데이터**입니다(2번 엄격, 3번 관대, 4번 중간. 1번이 메모를 남긴 항목에서 더 자주 다르게 판단).
- 1번 시트의 변형이라 채점자 간 일치도가 실제 사람 사이보다 높게 나옵니다. kappa 같은 지표가 어떻게 계산되는지 보는 용도이며, 보고서에는 "가상 채점(미리보기용)"으로만 씁니다.
- 실제 시트(`human/`)는 건드리지 않았습니다.
